# Spec Delta

## Purpose
为会话页面保留稳定的请求和响应数据结构，当前通过后端JSON示例数据展示列表、新建、改名与消息交互。正式会话存储路线尚未确定，不将文件解析、自建表或原生表作为本期已确认实现。

## ADDED Requirements

### Requirement: 会话演示接口
系统 SHALL 保留会话列表、创建、改名和消息接口，以固定JSON数据支撑页面。
#### Scenario: 查看演示页面
- **WHEN** 用户进入聊天页面
- **THEN** 展示明确标识的演示会话和消息，不把JSON示例回复描述为真实模型结果

### Requirement: 暂缓存储实现
系统 SHALL 不在本期聊天链路读取历史文件、SDK日志或会话表，不提供导入功能，不运行会话核对定时任务。
#### Scenario: 切换演示会话
- **WHEN** 用户切换页面中的会话
- **THEN** 返回对应JSON示例消息，不扫描或迁移真实历史
