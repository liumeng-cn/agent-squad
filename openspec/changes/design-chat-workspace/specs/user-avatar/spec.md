# Spec Delta

## Purpose
为用户身份提供稳定、可辨识且不依赖外部图片站点的几何头像，使聊天侧栏、个人菜单和资料弹窗展示一致，并在昵称变化或重新登录后保持相同图案和配色。

## ADDED Requirements

### Requirement: 稳定生成的几何头像
系统 SHALL 根据稳定用户业务ID生成版本化几何图案，不使用手机号或昵称作为种子，不请求外部头像网站。
#### Scenario: 修改昵称
- **WHEN** 用户修改或清空昵称并重新登录
- **THEN** 同一用户头像图案与配色保持不变

### Requirement: 统一资料展示
系统 SHALL 在登录、本人资料和资料编辑结果中返回同一头像定义；侧栏优先显示昵称，无昵称展示用户名。
#### Scenario: 空昵称
- **WHEN** 用户保存空昵称
- **THEN** 用户入口立即回退用户名，头像不变，完整手机号仅在本人资料展示

### Requirement: 头像渲染边界
头像数据 SHALL 采用有限风格、配色键及固定图案，不接收任意HTML、SVG或外部URL。
#### Scenario: 临时缺失头像数据
- **WHEN** 页面没有取得完整头像定义
- **THEN** 展示中性占位，不随机变化或暴露其他用户资料
