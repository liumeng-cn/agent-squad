# Spec Delta: Context & Memory / R04 R09

## ADDED Requirements

### Requirement: 长会话安全上下文窗口

平台 MUST 以模型真实输入预算选择最新用户要求、最近对话、权威任务事实和当前授权记忆；可使用带版本和来源边界的历史摘要，但不得静默遗漏最新用户要求或复活已删除/撤销的记忆。冻结执行重试复用一致快照。

#### Scenario: 超长对话
- **WHEN** 会话历史超过单次模型输入范围
- **THEN** 保留最新消息，按安全窗口/摘要选择历史材料，必要时明确提示省略，不能仅因对话增长而永久不可用

#### Scenario: 记忆失效
- **WHEN** 早期材料/记忆被用户删除、纠正或授权撤销
- **THEN** 新上下文不选过期摘要，旧冻结上下文经版本校验失效，敏感来源不通过摘要重新出现
