# 调研代码归档

这里保留固定 SDK 和 Redis 协议的可复现实验，不参与业务模块构建，不作为应用启动入口。根目录原 `experiments/` 已移除。

| 目录 | 保留原因 |
| --- | --- |
| sdk-contract | 固定 SDK 停止原因、日志导出、重启恢复等行为证据；保留已知失败断言，便于后续版本复核 |
| redis-wakeup | Streams 合并、确认、接管及通知丢失的协议实验，完整故障准入仍需继续验证 |

各目录 README 记录原实验范围。旧结果是历史证据，不代表当前整套业务已通过。归档不删除仍用于解释上游缺陷的源码，不复制进入生产代码。

持续使用的隔离数据库、浏览器验收入口统一放在 `tools/verification/`。业务回归测试仍在各模块标准测试目录。
