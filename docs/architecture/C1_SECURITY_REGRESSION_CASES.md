## 请求身份与密钥配置

| 用例 | 输入与前置 | 预期 |
| --- | --- | --- |
| 合法断言 | 网关签名、正确用户/方法/路径，未过期 | Server 识别签名主体 |
| 缺少断言 | strict=true，仅伪造 X-User-Id / X-User-Role | 401 |
| 本地开关被误打开 | strict=true 且 allow-unsigned-local=true，使用普通身份头 | 401 |
| 本地兼容 | strict=false 且 allow-unsigned-local=true，传入有效 UUID 和单一角色 | 接收本地开发身份 |
| 禁止本地兼容 | strict=false 且 allow-unsigned-local=false，使用普通身份头 | 401 |
| 非法本地身份 | 本地兼容模式下传入无效 UUID、逗号角色或空角色 | 401 |
| 伪造/修改断言 | 修改签名、userId、role、method 或 path | 401 |
| 断言失效 | 断言过期、颁发时间超前或期限超过 30 秒 | 401 |
| 错误密钥轮换配置 | 上一代只配置 key 或 key-id，两代 key-id 相同 | 启动失败 |
| 正确密钥轮换 | 当前与上一代有效密钥和各自 key-id | 两代断言按配置验证 |

执行状态：合法断言、缺少断言、伪造/修改、过期/超前/超期断言已由单元测试和真实 HTTP 双重覆盖；本地兼容与非法本地身份仅单元测试；密钥轮换配置仅单元测试。`strict=true` 且 `allow-unsigned-local=true` 的进程级组合尚未实测。
