# C1 请求身份与订阅撤权：回归用例清单

> 状态：设计清单 / NOT_RUN。仅针对本批变更；不得将未运行的用例标记为 PASS。

## 验收前置

- 在隔离测试数据库准备两个普通用户、两个管理员和各自独立 Session。
- Gateway / Server 使用一致的短效 HMAC 密钥；明确 local 与 prod 两种配置。
- 配置真实 HTTP/SSE 路由、独立测试 MySQL，不使用生产凭据或清理已有用户数据库。

## 请求身份与密钥配置

| 用例 | 输入与前置 | 预期 |
| --- | --- | --- |
| 合法断言 | 网关签名、正确用户/方法/路径，未过期 | Server 识别签名主体 |
| 缺少断言 | strict=true，仅伪造 X-User-Id / X-User-Role | 401 |
| 本地开关被误打开 | strict=true 且 allow-unsigned-local=true，使用普通身份头 | 401 |
| 本地兼容 | strict=false 且 allow-unsigned-local=true，传入有效 UUID 和单一角色 | 接收本地开发身份 |
| 禁止本地兼容 | strict=false 且 allow-unsigned-local=false，使用普通身份头 | 401 |
| 非法本地身份 | 本地兼容模式下传入无效 UUID、逗号角色或空角色 | 401 |
| 伪造/修改断言 | 修改签名、userId、role、method 或 path | 401 |
| 断言失效 | 断言过期、颁发时间超前或期限超过 30 秒 | 401 |
| 错误密钥轮换配置 | 上一代只配置 key 或 key-id，两代 key-id 相同 | 启动失败 |
| 正确密钥轮换 | 当前与上一代有效密钥和各自 key-id | 两代断言按配置验证 |

## 用户状态与长期订阅

| 用例 | 输入与前置 | 预期 |
| --- | --- | --- |
| 禁用用户新请求 | 用户被管理员禁用后，提交原来有效的已签名断言 | 403 |
| 禁用用户已有 SSE | 用户订阅建立后管理员禁用用户 | 下一次轮询停止推送，释放连接名额 |
| 跨用户断言 | 用户 A 断言访问用户 B 会话、消息、产物 | 业务资源不存在或按合同拒绝 |
| 重新启用 | 用户管理员重新启用后使用新的认证会话 | 可重新建立授权的请求 |
| 本地运行兼容 | 未开启 enforce-user-status 的本地模式 | 不要求本地账号存在于 sq_user |

## 风险与待验证

1. 这批代码未覆盖通用的 HMAC 请求重放去重；仍依赖 30 秒有效期、私网隔离及业务操作幂等。
2. 网关服务与 Server 的代理 URI、大小写、编码和前缀必须进行真实链路核对。
3. 测试两用户并发、账号禁用与已有任务的操作边界，不能仅以 HTTP 401/403 证明全部安全点覆盖。
4. 未测试 SDK、模型调用、任务恢复、副作用幂等与跨进程切换，C1–C4 仍不可上线。
