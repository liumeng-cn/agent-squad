## 视觉基线

- 字体：系统中文无衬线；正文16px/1.6，主要标题20–24px，辅助信息12–14px。
- 背景#f8f9fb、正文#17232e、次要文字#687782、边框#e4e8ed；主色#176858。警示采用柔和琥珀底色，同时显示文字。
- 8px间距体系；普通按钮高40px、圆角8px；卡片12px。清晰聚焦态与禁用态，颜色不能是唯一状态提示。
- 桌面侧栏248px；正文控制行长，详情按需展开。窄屏折叠侧栏，审批动作纵向排列，不缩小字体塞进桌面布局。
- 运行时输入区禁发独立目标，保留停止与新对话。等待输入走原交互卡，不重新发送目标。
- 技能/连接/记忆/管理员页沿用相同外壳、表单、列表和抽屉；按[Web行为设计](../web-console.md)实施，不另起风格。
