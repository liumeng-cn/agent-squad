# 聊天页面审阅

正常聊天入口保留：发送、模型执行、流式快照、停止与继续沿用原有 SDK 链路。ChatService 负责消息操作，ChatRuntimeService 访问当前 SDK 会话，ChatEventStreamService 提供 SSE；当前会话内容通过 SDK 公开接口读取。

固定 JSON 只用于历史列表和三个示例会话。新建和改名接口的数据结构暂留，当前回显不持久化；正式历史查询和存储适配后续实现。不提供历史导入、文件转换或定时核对。

公共异常与当前用户入口统一归 common。侧栏使用轻描边胶囊按钮及 SVG 图标，折叠后隐藏整条侧栏，左上角保留品牌与工具栏。

前端构建及 34 项测试通过，后端 package 及聊天回归测试通过；服务已重启。
