# 设计评审与实施门槛 v0.2

2026-10-20。本轮替换旧参考草稿，统一 Java + AgentScope 的对象、职责、公共 API 和业务 DDL。未创建应用、安装依赖、运行 SQL、启动服务或调用真实模型。

## 已形成的设计

- R01–R12 保持；GoalTask 与 Session/Turn/Run 明确区分，多轮协调属于原用户目标。
- SDK 管推理、局部状态和 journal；平台管目标、跨 Worker 协作与副作用；不双写可裁决执行状态。
- 平台事务与 SDK 提交用 Command、稳定 key、原生导出幂等桥接；逐个列出崩溃窗口。
- Worker 接管、等待/回复、取消、核对、完成候选与最终提交都有条件和恢复路径。
- 接口、DTO、表结构、事件载荷及主线反例可追溯；静态检查不再按旧 57 接口/27 表统计。

## 阻止进入生产的验证项

| 项目 | 设计选择 | 尚须验证 |
| --- | --- | --- |
| SDK | 固定 v2.1.0-BETA1 候选，不依赖 main | 4个核心POM已通过只读获取检查；仍需JAR/传递依赖/构建验证、稳定版本迁移与Beta风险评审 |
| 应用依赖 | Java 21、Boot MVC/MyBatis；对齐上游 4.0.4 兼容基线后选受支持 patch | Jackson 2/3 边界、Reactor、模型模块、迁移和数据库组合构建 |
| 框架存储 | journal/inbox 单一权威，共享 JDBC/原子存储 | 已提取标签基础DDL；仍需制品/SQL验证、CAS 与 writer fence、禁自动建表、备份恢复 |
| 委派 | 持久 Job + HarnessAgent，禁自由后台 spawn | 固定标签禁用开关、恢复 factory、跨 JVM 同 Job 与原生输入不重复 |
| 平台/SDK 桥接 | 独立事务、幂等、导出回执 | 所有提交前后杀进程的窗口；resume/response 原生控制幂等核对 |
| 工具 | 独立账本/执行 gate/核对 | 外部成功丢回执、旧执行器晚到、授权变更后不发新请求 |
| 记忆 | 显式写入、关闭自动 hooks/tools、删除代数 | 实际关闭范围、旧压缩上下文清理/替代 Binding，不复活删除内容 |
| SSE | 原生持久导出→公开事件→一致快照 | 水位、脱敏、跨实例回放、半答案替换及慢连接隔离 |
| 沙箱 | 框架适配+隔离执行 | 驱动配额/网络/挂载/快照是否真正满足；不开放未达标脚本 |
| 生产目标 | M08 的 RPO/RTO/可用性/保留初值 | 容量、成本、HA、备份及故障演练；目标值不是已达成承诺 |

这不是要求用户此刻批准实现。当前仍按模块继续评审设计；有反例时同步修改模块、契约、DDL及 ADR，禁止只改一份文件。

## Spring代码评审要求

后续实现必须检查：无内部类/嵌套DTO、无构造方法注入或Lombok隐式注入；使用@Resource；类与核心方法注释清晰；关键日志包含阶段/结果/原因及适用ID，脱敏且不重复刷屏。当前未生成Spring源码，不能把规范已写入当成代码已符合。
