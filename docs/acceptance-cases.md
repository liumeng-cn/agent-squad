# 主线验收场景

这些是后续实现/实验的验收用例，本轮没有执行。每个用例必须记录固定 SDK/配置版本、故障注入点、平台与原生日志、外部操作次数及可重复步骤。

| 用例 | 触发 | 必须断言 |
| --- | --- | --- |
| A01 | 同键重送/同键换输入 | 一个 GoalTask；后者 409，无第二次执行 |
| A02 | 平台受理后、SDK submit 前杀 JVM | Command 重投到原 Binding，不丢目标 |
| A03 | SDK 接受后、平台收据前杀 JVM | 同 key 补回执，同一 Turn |
| A04 | 直接回答、单 Worker、双并行、串行 | 相同主线；依赖未满足不启动下游 |
| A05 | 同 Job 两实例及迟到提交 | 一个有效业务 guard；原生日志拒绝旧 writer，旧工具/结果拒绝 |
| A06 | 一个成功分支、另一分支崩溃 | 只恢复后者，不重复成功分支；结果候选不提前算成功 |
| A07 | INPUT/APPROVAL 挂起后重启 | 查原 requestId、原 Job/Task；重复答复不重复执行 |
| A08 | 写操作成功但本地回执丢失 | UNKNOWN 阻止结束；查证后映射原 toolCallId 继续 |
| A09 | Plan 已写而 SDK tool result 未提交 | 原逻辑键返回相同 Plan/Jobs，无重复节点 |
| A10 | 新计划替代在途旧计划 | 旧结果不推进新依赖；原副作用证据不删除 |
| A11 | 取消与工具派发/用户回复/恢复竞争 | 屏障后不发新业务；已 IN_FLIGHT 核对完才收尾 |
| A12 | 原生 Turn 完成但公开导出失败 | 补投影而不再推理；完成候选有持久成功证据才发布 |
| A13 | 断线、跨实例读、半答案重生成 | 一致水位，无重复业务；revision 替换而不拼接 |
| A14 | 两用户同名会话/技能、恶意 Skill | 身份由平台建立，不能越权/自动安装/宿主执行 |
| A15 | 显式记忆更新删除，旧摘要仍含原值 | 当前请求重建授权上下文，旧 checkpoint 不复活；无法清理时阻塞 |
| A16 | 并行模型/摘要/工具重试 | 全局预算不超，未知计费不提前释放 |
| A17 | 新能力按 Schema 注册 | Master 无业务代码改动；Skill 可自动发现使用 |
| A18 | DB/对象存储失败、备份缺窗口、沙箱退出 | 无持久保障不发写操作；缺失文件阻塞；外部未知先核对 |

需求追踪以 `contracts/traceability.json` 对应到模块、DTO、公共操作及此用例，不用接口数量证明满足需求。

前端B01–B15在[页面设计](web-console.md)中定义，与后端A场景联合验收；后端接口成功不能代替浏览器流程通过。
